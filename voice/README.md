# Teacher voice recordings

Upload your introduction recordings here. Record them in the course: Staff → Admin panel → My voice.

File names must be exactly `course-criterion`, for example:

| Course | Files |
|---|---|
| Grade 6 | 6-A, 6-B, 6-C, 6-D |
| Grade 7 | 7-A, 7-B, 7-C, 7-D |
| Grade 8 | 8-A, 8-B, 8-C, 8-D |
| Grade 10 Design | 10-A, 10-B, 10-C, 10-D |
| Grade 10 IT | 10IT-A, 10IT-B, 10IT-C, 10IT-D |

Accepted formats: .webm, .m4a, .mp4, .mp3. If a file is missing, the course uses the computer voice.
